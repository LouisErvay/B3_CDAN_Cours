# Explanation for noobs about SmartDataAPI.

## What is SmartDataAPI?

The **SmartDataAPI** is a online server that allows you to retrive data to use in your application.  
To do that, you need to request the server with the **HTTP** protocol.

## HTTP Methods: GET and POST

This protocol has several methods, the more common and which will be used in this project are **GET** and **POST**.  
The **GET** format lets you question the server with a URL only.  
On the other hand, the **POST** format lets you question the server with a URL and à body, the body contains data that specifies the question you want to ask the server.

## How to Use GET and POST Methods

So, you can see in the documentation, the **GET** and **POST** methods are described.  
To request the **GET** you have 4 params that you can use to filter the data you want to retrieve. They are all optional.  
To request the **POST** you have a body that you can use to filter the data you want to retrieve.  
All examples of uses are described in the documentation.

## JSON Format

The server will return the data you requested in **JSON** format.  
The **JSON** format is a format that allows you to store data in a structured way.  
It is a very common format to store data in web applications.  
The structure of the **JSON** used in **SmartDataAPI** is detailed in the documentation.

## Using the Retrieved Data

Once you have the data you want to use, you can use them in your application for your own needs.  
You can display them in a web page or in a mobile application.  
You can also use them for analytics or for other purposes.
