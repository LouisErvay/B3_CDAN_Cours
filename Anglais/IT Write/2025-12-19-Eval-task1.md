# SecureAuthAPI documentation

## What is SecureAuthAPI?

The **SecureAuthAPI** is service that allows you to authenticate users and to manage their sessions inside the application of our company.  
This service **must be implemented in all the applications** of our company.

It uses **OAuth2.0** protocol to authenticate users, with **JWT** tokens.

## Quick reminder about OAuth2.0 and JWT workflow

**OAuth2.0** is a protocol that uses **JWT** tokens to authenticate users.  
The user needs to authenticate himself by providing his credentials to the server.  
In our case, the credentials are the **email** and the **password** of the user.

The server will then return 2 tokens: an **access token** and a **refresh token**:

-   The **access token** is used to access the resources of the application.
-   The **refresh token** is used to refresh the **access token** when it is expired.

The access token is valid for 30 minutes.  
The refresh token is valid for 1 hour.

When the UI wants to access a protected resource, it will need to send the **access token** in the request headers like this: `Authorization: Bearer <access_token>`.  
if the access token is expired, the server will return a `CODE 401 Unauthorized` error.  
In this case, the UI will need to refresh the **access token** by sending the **refresh token** to the server. The server will then return a new **access token** and a new **refresh token**.

## The API endpoints

### POST `/api/v1/auth/login`

**Description:**  
Authenticate a user and return the **access token** and the **refresh token**.

**Request Body Example:**

```json
{
    "email": "john.doe@example.com",
    "password": "password"
}
```

**Response Example:**

```json
{
    "access_token": "1234567890",
    "refresh_token": "1234567890"
}
```

**Response Codes:**

-   `CODE 200 OK`: The user is authenticated and the **access token** and the **refresh token** are returned.
-   `CODE 401 Unauthorized`: The user credentials are invalid.

### POST `/api/v1/auth/refresh`

**Description:**  
Receive a **refresh token** and return a new **access token** and a new **refresh token**.

**Request Body Example:**

```json
{
    "refresh_token": "1234567890"
}
```

**Response Example:**

```json
{
    "access_token": "1234567890",
    "refresh_token": "1234567890"
}
```

**Response Codes:**

-   `CODE 200 OK`: The **refresh token** is valid and the new **access token** and the new **refresh token** are returned.
-   `CODE 401 Unauthorized`: The **refresh token** is invalid.

### POST `/api/v1/auth/logout`

**Description:**  
Logout a user and invalidate the **access token** and the **refresh token** associated to the user.

**Request Body Example:**

```json
{
    "access_token": "1234567890"
}
```

**Response Example:**

```json
{
    "message": "User logged out successfully"
}
```

**Response Codes:**

-   `CODE 200 OK`: The user is logged out and the **access token** and the **refresh token** are invalidated.
-   `CODE 401 Unauthorized`: The **access token** is invalid.

## Errors codes

Here is the list of the errors codes that the server can return:

-   `CODE 400 Bad Request`: The request is invalid.

```json
{
    "message": "Invalid request"
}
```

-   `CODE 401 Unauthorized`: The request is unauthorized.

```json
{
    "message": "Unauthorized"
}
```
